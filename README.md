🚀 Apa itu Proyek Ini?
---
Proyek ini dirancang sebagai prototipe website berbasis HTML dan CSS yang berfungsi sebagai katalog atau portal game. 
Berdasarkan struktur foldernya, website ini memiliki halaman utama untuk memamerkan berbagai judul game ternama, halaman akses masuk (login) untuk pengguna, s
erta didukung oleh kumpulan aset gambar visual dan tata letak stylesheet yang terpusat.
---

✨ Fitur-Fitur Utama Website

1. 🏠 Halaman Utama & Katalog Game ( indeks.html )

Portal Katalog Game: Halaman utama yang menyajikan daftar atau galeri game.

Struktur Navigasi Utama: Menjadi kerangka dasar untuk menampilkan konten web, memuat elemen-elemen kerangka situs, dan menghubungkan pengguna dengan halaman lain.

2. 🔐 Halaman Autentikasi ( login.html )

Akses Pengguna: Formulir antarmuka bagi pengguna atau admin untuk masuk ke dalam sistem website.

Keamanan Dasar: Merupakan gerbang awal (UI) sebelum pengguna bisa mengakses fitur-fitur spesifik atau dashboard di dalam website.

3. 🎨 Sistem Desain & Antarmuka ( style.css )

Desain Visual Utama: File stylesheet yang mengatur keseluruhan tampilan website (warna, tata letak, tipografi, dan spasi).

Pengaturan Layout: Kemungkinan menggunakan teknik Grid atau Flexbox untuk memastikan gambar-gambar game pada halaman utama tertata dengan rapi.

4. 🖼️ Galeri Aset Visual ( img/ )

Kumpulan Cover/Banner Game: Menyimpan aset-aset gambar (format .jpg dan .png) untuk mendukung visual di halaman HTML.

Katalog Judul Populer: Berisi aset gambar dari berbagai judul game populer seperti Resident Evil, Tekken, Mortal Kombat 11 (Mk11), Street Fighter 6 (sf6), Omori, Black Myth: Wukong, Ark, dan lainnya.
